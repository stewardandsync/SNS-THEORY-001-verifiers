# SNS-THEORY-001 Verifiers

This folder packages the computational verifier code and archived cluster-output artifacts for SNS-THEORY-001. It contains the original production verifiers recovered from `cluster-docs`, plus three clean release implementations for the previously missing Z/4Z phase/headline checks and the Z/9Z `(K=7, R=7)` full seed-space enumeration.

## Reproduction Instructions

Use Python 3.10+ from this directory. The pure-Python verifiers require only the standard library. The NumPy/Numba production verifier requires `numpy` and `numba`.

```bash
cd /home/ahmed/cluster-docs/SNS-THEORY-001-verifiers
python3 z4z_headline_cells.py
python3 z4z_phase_diagram.py
python3 z9z_full_enumerator_77.py
python3 parallel_runners/z4z_headline_cells_parallel.py
python3 parallel_runners/z4z_phase_diagram_parallel.py
python3 parallel_runners/z9z_full_enumerator_77_numba.py
python3 theorem13_witness_verifier.py
python3 independent_pure_python_t13.py
python3 independent_z4z_verifier.py
python3 independent_K8R7_spot_check.py
python3 c_param_delta3_exhaust.py
```

Several scripts are intentionally exhaustive. `z9z_full_enumerator_77.py`, `z4z_phase_diagram.py`, and `c_param_delta3_exhaust.py` may run for a long time depending on CPU and parameter choices. Do not launch them casually on shared hardware without confirming runtime expectations. The `parallel_runners/` scripts are the all-core runners used on USLMAX003 to regenerate the archived JSON outputs; they preserve the original clean verifier files unchanged and require `numpy` and `numba` for the Z/9Z full enumerator.

## Archived Outputs

The `archived_outputs/` folder contains extracted cluster artifacts:

- `gap8_uslmax005/`: 49 files extracted from `cluster-docs/uslmax-workspace/kernel/cluster_snapshots/gap8_uslmax005_20260507T000000Z.tgz`.
- `gap9_USLMAX003/`: 145 files extracted from `cluster-docs/uslmax-workspace/kernel/cluster_snapshots/gap9_USLMAX003_20260507T000000Z.tgz`.
- `generated/Z4Z_headline_cells.json`: regenerated on USLMAX003 with 24 worker processes; all assertions passed for Theorems 20-21 and Remark 22.
- `generated/Z4Z_phase_diagram_complete.json`: regenerated on USLMAX003 with 24 worker processes; all 49 cells completed and all assertions passed for Theorems 19-21.
- `generated/Z9Z_K7R7_full_enumeration.json`: regenerated on USLMAX003 with 24 Numba threads; all `4,782,969` seeds were enumerated, `7,014` max-attaining seeds and `501` free orbits were confirmed, and all assertions passed for Theorem 24.

The gap folders are original checkpoint/output artifacts. The `generated/` folder contains regenerated outputs from the public verifier package.
